## Decisions

- Python 3.12 instead of Homebrew's default 3.15: no wheels for
  manifold3d/CadQuery on 3.15 (specs/toolchain.md).
- OpenSCAD snapshot cask instead of stable: stable is disabled for
  failing Gatekeeper; snapshot has the Manifold backend.
- Input models in `models/`, committed; generated files in `out/`, not.
- Previews via OpenSCAD import() rather than trimesh's viewer, which
  needs a display.

## How to run

- `make build`       create venv and install requirements
- `make check`       lint and smoke test (needs openscad on PATH)
- `make run`         mesh info for MODEL
- `make printcheck`  printability report for MODEL
- `make preview`     PNG renders of MODEL in out/
