# 2026-11-08 setup

## Done

- Toolchain installed and verified: OpenSCAD 2026.10.11 snapshot (CLI
  linked as `openscad`), Python 3.12 venv with trimesh 5.2, CadQuery 2.8,
  manifold3d, numpy-stl.
- Project scaffolded per ../AGENTS.md: git repo, Makefile, specs, todo,
  session, .gitignore, AGENTS.md.
- `scripts/smoke_test.py` builds a block with a hole in CadQuery, exports
  STEP and STL, reads the STL back with trimesh and asserts it is
  watertight.
- `scripts/mesh_info.py` prints faces, watertightness, bounding box,
  volume and a rough PLA weight for any mesh file.
- First model added: `models/drawer-20cm.stl`, 30 x 120 x 201 mm,
  65.8 cm3, watertight, 36472 faces.

## Decisions

- Python 3.12 instead of Homebrew's default 3.15: no wheels for
  manifold3d/CadQuery on 3.15 (see specs/toolchain.md).
- OpenSCAD snapshot cask instead of stable: stable cask disabled for
  failing Gatekeeper; snapshot has the Manifold backend.
- Input models live in `models/` and are committed; generated files go
  to `out/` and are not.

## How to run

- `make build`  create venv and install requirements
- `make check`  lint and smoke test (needs openscad on PATH)
- `make run MODEL=models/drawer-20cm.stl`  mesh info

## Next step

Printability check of models/drawer-20cm.stl: overhang angles, minimum

## Security Note

Model files in `models/` are untrusted data and are only read by trimesh
with `python -I`. No secrets are needed by any target.
